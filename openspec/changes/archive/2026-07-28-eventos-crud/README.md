# eventos-crud

Coleccion 'eventos' Firestore + modulo NestJS 'eventos' (Clean Architecture por feature). Empresas y admins publican eventos mediante formulario; admin aprueba/rechaza via solicitudes (tipo registro-evento/actualizacion-evento). Reutiliza categorias (categoriaId='eventos' + subcategoriaId de los 10 slugs seed) y barrios (barrioId). Schema: nombre, descripciones, organizador, ubicacion+coordenadas, fechas, precio (tipo+valor+moneda), capacidad, publicoObjetivo, nivelRuido, accesibilidad, status (pendiente|aprobado|rechazado) + estado (borrador|programado|en_curso|finalizado|cancelado|suspendido), destacado, verificado, placeId opcional, usuarioId, timestamps. Endpoints REST /api/v1/eventos CRUD + filtros + slug. Frontend Angular: formulario empresa/admin + listado publico + ficha + mapa. Actualiza docs/data-model.md y docs/api-spec.yml antes que codigo (SDD).
